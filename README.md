# CRM Projesi

Bu proje, müşteri ilişkileri yönetimi (CRM) için geliştirilmiş bir full-stack uygulamadır.

## Özellikler
- Aday cari kartı yönetimi
- Görev ve aktivite takibi
- Kullanıcı yönetimi (admin, manager, staff rolleri)
- Rota Cloud ile senkronizasyon
- Raporlama

## Kurulum
1. Depoyu klonlayın: `git clone https://github.com/ItsBurakVatan/crmProject`
2. Bağımlılıkları yükleyin:
   - Backend: `cd backend && npm install`
   - Frontend: `cd frontend && npm install`
3. `.env` dosyasını oluşturun (örnek aşağıda).
4. Sunucuyu başlatın:
   - Backend: `npm start`
   - Frontend: `npm start`
